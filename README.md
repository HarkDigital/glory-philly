# Glory Beer Bar & Kitchen — site concept

A concept site for Glory Beer Bar & Kitchen (gloryphilly.com, 126 Chestnut
Street, Old City Philadelphia), built on the Hark concept engine with the
**Resonance** concept as its guide: a photoreal product film (studio key,
softbox strips, liquid highlights, damped springs, editorial type), poured as
beer in Glory's own room — exposed brick, Edison bulbs, a long oiled bar.
Chapters are joined by **the pour**: beer fills the frame with carbonation
and a foam head, then drains leaving foam lacing. All copy is verbatim from
gloryphilly.com and the @glorybeerbarandkitchen Instagram bio; photos are
theirs.

**Live (noindex):** https://harkdigital.github.io/glory-philly/

```bash
npm install
npm run dev
npm run build
```

Kit (`src/kit/`): `beer.ts` (glassware, beer, foam), `bar.ts` (bar top,
brick), `pace.ts` (StoryClock), `images.ts` (off-thread photo loading).
